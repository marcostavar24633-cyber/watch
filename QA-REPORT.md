- Старый монолитный index.html заменён новой главной страницей.

- Навигация между основными страницами.
- Мобильное меню.

## 4. Известные ограничения

- Не выполнен реальный браузерный прогон.
- Не запускались Lighthouse, HTML validator, axe, Playwright или тесты скринридера.
- Не измерялись LCP, INP, CLS и объём переданных ресурсов.
- Не проверялись реальные мобильные устройства и браузеры.
- Не проверена работа GitHub Pages по фактическому опубликованному URL.
- Карточки используют процедурную SVG-графику, а не фотографии реальных товаров.
- product.html использует query-параметр ID как демонстрационный шаблон. Для полноценного SEO-каталога нужны отдельные статические URL товаров или генерация страниц.
- Подборщик является образовательным прототипом и не выдаёт проверенную рекомендацию модели.
- Корзина, checkout, приём заявок, оплата, доставка и серверная синхронизация не подключены.

## 5. Критерии перед следующим релизом

1. Открыть все страницы в браузере через HTTP(S).
2. Проверить мобильные ширины 360, 390, 768, 1024 и 1440 px.
3. Пройти каталог, фильтры, сортировку, карточку, сравнение и избранное.
4. Проверить поведение при пустом/повреждённом localStorage.
5. Проверить клавиатуру, фокус, screen reader labels и контраст.
6. Выполнить Lighthouse и сохранить отчёты.
7. Проверить публикацию в GitHub Pages только после отдельного разрешения.
8. После получения реального каталога проверить спецификации, изображения и совместимость.
